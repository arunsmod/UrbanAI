## Key Topics

### Getting Started
1. Read [CONTRIBUTING.md](guides/CONTRIBUTING.md) for development setup
2. Review [architecture.md](architecture.md) for system design
3. Check API docs in [api/](api/) folder

### Deployment
1. See [deployment/DEPLOYMENT.md](deployment/DEPLOYMENT.md) for production setup
2. Configure the selected hosted data provider following the deployment guide
3. Review security considerations and monitoring

### Development
1. Follow code style in [CONTRIBUTING.md](guides/CONTRIBUTING.md#code-style)
2. Run tests as documented in [guides/CONTRIBUTING.md](guides/CONTRIBUTING.md#testing)
3. Review design patterns in [architecture.md](architecture.md)

## Documentation Standards

All documentation should include:
- Clear section headers
- Code examples where applicable
- Links to related sections
- Troubleshooting information for setup/deployment

For new documentation, add it to the appropriate section and update this index.
